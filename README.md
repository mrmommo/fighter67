1. SceneFactory chỉ dùng cho các màn hình "Cốt lõi" (Core Lifecycle) của FXGL
Trong engine FXGL, vòng đời game chỉ có sẵn một vài trạng thái màn hình mặc định cố định, bao gồm:

Startup Scene (Màn hình khởi động engine)
Intro Scene (Màn hình chiếu logo hãng game)
Loading Scene (Màn hình chờ tải dữ liệu)
Main Menu (Màn hình chính)
Game Menu (Màn hình menu hiện ra khi đang chơi mà bấm ESC)
